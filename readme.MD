# DETF (Don't Eat that Frog)
 > it is a small web app which uses community votes to find the best excuse to procrastinate.

![screenshot.png](https://cdn.hackclub.com/019ea374-cf43-7122-bc0a-e6d51f0f3ccb/Screenshot%202026-06-08%20at%2012.29.41%E2%80%AFAM.png)

# Features
- /add - add an excuse
- /all - see all excuses
- /own - see your excuses
- /admin - page for admin to manage excuses
- /hidden - page for admin to see hidden excuses which were reported by users

# Third-Party connectors
- Neon Database
- Slack for User's Display Name retrieval
- Hack Club Auth for User Auth
- Hack Club AI for reviewing and ranking the excuses by points
